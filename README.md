# Pacote-lang - EN
An interpreted programming language that runs on the JVM

---

Pacote-lang is a weakly and dynamically typed programming language.

Pacote-lang belongs to the group of languages that run on the Java Virtual Machine (JVM), allowing it to be used on various computer architectures, such as:
- x86 and x86-64
- ARM
- PowerPC
- Among others

It is also cross-platform, meaning it can run on operating systems such as:
- Windows
- Linux
- macOS
- Android
- And even some embedded systems

---

The language currently supports arithmetic operations such as addition, subtraction, multiplication, and division.

It also supports dynamically typed variables.

Boolean values and null are also supported by the language.

Variables are declared without any prefix, very similar to Python.

Syntax example:
```
a = 10
x = 5.3
b = a + x
x = a = b
```

To run the language, simply write your code in the `code.pact` file located alongside the `Main` file, then execute `Main`.
